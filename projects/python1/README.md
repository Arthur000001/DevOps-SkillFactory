# kcsv-app — Шаблон приложения для обработки CSV из Kaggle

Готовый к тиражированию CLI-шаблон на Python для обработки больших CSV.  
Подходит для запуска **локально**, в **Docker** и для публикации колёсика (`.whl`) во внутренний PyPI.

---

## Возможности
- Принимает путь к CSV (в т.ч. очень больших).
- Авто-определение разделителя (или можно указать вручную).
- Потоковая обработка чанками (без загрузки всего файла в память).
- Сводная статистика по столбцам (типы, пропуски, базовые метрики).
- Сэмпл строк в отдельный файл.
- Гистограммы для числовых столбцов (PNG).
- Логи в консоль + файл.
- Конфигурация через CLI / ENV / файл.
- Готовые: `Dockerfile`, `Makefile`, пример CI.

---

## Быстрый старт (локально)

```bash
# 1. Установка
python -m venv .venv && source .venv/bin/activate
pip install -U pip
pip install .

# 2. Запуск
kcsv run path/to/data.csv --out out_dir

# Все опции
kcsv run --help
```

---

## Быстрый старт (Docker)

```bash
# Сборка
docker build -t kcsv:latest .

# Запуск (с пробросом папки с данными и результатами)
docker run --rm -v "$PWD:/work" kcsv:latest   kcsv run /work/path/to/data.csv --out /work/out
```

---

## Артефакты в выходной папке

- `summary.json` — общая сводка по датасету
- `columns.csv` — статистика по каждому столбцу
- `sample.csv` — сэмпл N строк (если задан `--sample`)
- `plots/*.png` — гистограммы по числовым столбцам
- `kcsv.log` — логи выполнения

---

## Тиражирование

- **Пакет**: собирайте `wheel` и публикуйте во внутренний PyPI.
- **Контейнер**: пушите `kcsv:version` в Docker Registry, фиксируйте базовый образ.
- **Повторяемость**: все версии зависимостей фиксированы в `pyproject.toml`.
- **Расширяемость**: разработчики могут добавлять трансформации в `kcsv/processing.py`.
