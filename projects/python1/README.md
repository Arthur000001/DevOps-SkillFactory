
# kcsv-app — Шаблон приложения для обработки CSV из Kaggle

Готовый к тиражированию шаблон: CLI-приложение на Python для обработки больших CSV.
Подходит для запуска локально, в Docker и для публикации колёсика (`.whl`) во внутренний PyPI.

## Возможности
- Принимает путь к CSV (в том числе очень большой).
- Авто-определение разделителя (или задаётся вручную).
- Потоковая обработка чанками (без загрузки всего файла в память).
- Сводная статистика по столбцам (типы, пропуски, базовые метрики).
- Семпл строк в отдельный файл.
- Гистограммы для числовых столбцов (PNG).
- Логи в консоль + файл.
- Конфигурация через CLI/ENV/файл.
- Готовый Dockerfile, Makefile и CI-пример.

## Быстрый старт (локально)
```bash
# 1) Установка
python -m venv .venv && . .venv/bin/activate
pip install -U pip
pip install .

# 2) Запуск
kcsv run path/to/data.csv --out out_dir

# Все опции
kcsv run --help
```

## Быстрый старт (Docker)
```bash
# Сборка и запуск
docker build -t kcsv:latest .
docker run --rm -v "$PWD:/work" kcsv:latest kcsv run /work/path/to/data.csv --out /work/out
```

## Структура артефактов в выходной папке
- `summary.json` — общая сводка по датасету
- `columns.csv` — статистика по каждому столбцу
- `sample.csv` — семпл N строк (если задан `--sample`)
- `plots/*.png` — гистограммы по числовым столбцам
- `kcsv.log` — логи выполнения

## Тиражирование
- Пакет: собирайте `wheel` и публикуйте во внутренний репозиторий.
- Контейнер: публикуйте `kcsv:version` в регистри, фиксируйте базовый образ.
- Повторяемость окружения: версии зависимостей фиксируются в `pyproject.toml`.
- Расширение функциональности: разработчики могут добавлять трансформации в `kcsv/processing.py`.
