# Docker команды и их использование

## Работа с контейнерами

| Команда       | Значение                                                                 | Опции                                                                 |
|---------------|--------------------------------------------------------------------------|------------------------------------------------------------------------|
| run           | Запуск контейнера.                                                       | - **-d** — запуск контейнера в *detached* (фоновом) режиме;<br>- **-t** — подключение терминала (tty);<br>- **-i** — интерактивный режим;<br>- **--name** — задание имени контейнера;<br>- **--mount (-v, --volume)** — монтирование файлов из хостовой ФС в ФС контейнера;<br>- **--rm** — удаление контейнера после завершения работы;<br>- **-p** — проброс портов (формат: `-p порт_хоста:порт_контейнера`). |
| exec          | Подключение к уже запущенному контейнеру и запуск в нём команд.           | - **-d** — выполнение команды в фоновом режиме;<br>- **-t** — подключение терминала (tty);<br>- **-i** — интерактивный режим;<br>- **-e** — назначение переменной окружения. |
| cp            | Копирование файлов между локальной ФС и контейнером.                     |                                                                        |
| inspect       | Вывод максимальной информации о контейнере.                              |                                                                        |
| logs          | Вывод **stdout–stderr** потоков контейнера.                              |                                                                        |
| ps            | Вывод списка контейнеров.                                                |                                                                        |
| stop/kill     | Остановка/убийство контейнера (аналог SIGTERM и SIGKILL в Linux).        |                                                                        |
| start         | Запуск ранее остановленного контейнера.                                  |                                                                        |
| import/export | Импорт/экспорт ФС контейнера в/из **tar**-файла.                         | По умолчанию работает через **stdout**/**stdin**. Экспортированная ФС может использоваться для создания новых образов. |

## Работа с образами

| Команда             | Значение                                                                 |
|---------------------|--------------------------------------------------------------------------|
| build               | Сборка образа из **Dockerfile**.                                         |
| history             | Просмотр истории создания образа (действия из **Dockerfile**).           |
| inspect             | Вывод максимальной информации об образе.                                |
| save/load           | Выгрузка/загрузка образа в/из **tar**-файла (часто для переноса между машинами). |
| ls                  | Вывод списка доступных образов.                                         |
| pull/push           | Команды работы с хранилищем образов.                                    |
| rm                  | Удаление образа.                                                        |
| docker system prune | Очистка диска от неиспользуемых контейнеров, образов, сетей и кеша.      |
